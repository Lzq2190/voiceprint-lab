DFT 把信号"缠"到圆上，看质心偏不偏对应讲义第 4 讲

想象一段录好的信号，你把它按某个频率"缠绕"到一个圆上：第 n 个采样点，就把它转到 −2π f n / Fs 这个角度上。然后取所有点的重心。

如果 f 恰好是信号里真实存在的频率，所有点会朝同一个方向堆叠，重心就远离圆心；如果 f 对不上，点会均匀铺满一圈，重心正好回到圆心。DFT 的第 k 个值，就是这个重心离圆心有多远。

信号里的真实分量位置 当前探测的 f
为什么峰值高度是幅值的一半？因为一个实正弦 A·sin(2πf₀t) 的能量一半在 +f₀、一半在 −f₀。你把 f 调到 +f₀ 时，只收到了这一半，所以重心距离约等于 A/2。这是实信号频谱的常态，不是 bug——第 4 讲里"幅度谱要乘 2 补回来"说的就是这件事。

它和讲义里那个公式是同一件事

# 讲义第 4 讲：X[k] = Σ x[n]·e^(−j2πkn/N) # 这个页面在做的： X = sum( x[n] * (cos(θ) + j·sin(θ)) for n, θ = −2π·f·n/Fs ) mag = abs(X) / N # 除以 N，就是"平均位置"，即质心 # 换句话说：DFT 是在量"信号和某个频率的相似程度" # 本质是一次内积 / 投影，不是某种神秘的变换

三个值得亲手试的实验

做什么先预测会看到
只留 100 Hz 分量，把 f 拖到 100重心会不会在圆外？图形收成一朵花瓣，重心明显偏出
f 拖到 150（两个分量之间）重心回圆心吗？回到圆心附近，读数接近 0
打开宽带噪声，f 停在 100峰值会变高还是变矮？几乎不变——噪声在整圈均匀铺开，重心互相抵消
第三条是重点：这就是为什么 DFT 抗得住白噪声。噪声不是被"滤掉"了，是它在每个频率上都贡献一点点、方向随机，平均下来就抵消了。而真实频率上的分量方向一致，越加越大。

梯度不是猜的，是一串"局部斜率"乘起来对应讲义第 8 讲

这个网络很小：2 个输入 → 2 个隐层神经元（tanh）→ 1 个输出（sigmoid），损失用平方误差。9 个参数，每一个都能拖。

重点不是网络本身，而是看右侧那块"链式分解"：一个参数的梯度，等于误差往回传时，每一层乘上自己那一小段斜率。拖动权重，你会同时看到前向值、梯度和数值验证三者一起变。

拖动时注意一件事：把某个权重拖过它该在的位置，梯度的符号会翻。梯度不是"往哪边走更好"的指令，它只是当前这一点上，损失上升最快的方向。负号才是"往下走"。
